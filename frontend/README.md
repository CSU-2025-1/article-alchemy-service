# Article Alchemy Front-end

## Установка зависимостей

Для установки зависимостей необходимо выполнить команду

```sh
npm i
```
## Запуск

Для запуска проекта в режиме разработки необходимо выполнить команду

```sh
npm run dev
```

#### 1. Структура проекта

- **components** — общие переиспользуемые компоненты.
- **pages** — страницы приложения. Внутри можно создавать собственные компоненты, чтобы избегать перегруженности страниц.
- **hooks** — пользовательские хуки.
- **context** — провайдеры контекста для управления глобальным состоянием или логикой.
- **services** — модуль для бизнес-логики и взаимодействия с API.
- **utils** — вспомогательные функции.
- **assets** — статика, такая как изображения, иконки, шрифты и т.д.

#### 2. Написание стилей для компонентов

Все стили компонентов реализуются с помощью **styled-components**. Для каждого компонента создается отдельный файл стилей. Пример именования файла: `ComponentName.styles.js`.
